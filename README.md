# Portifolio Victor

Projeto frontend com React, TypeScript, Vite e Tailwind CSS.

## Requisitos

- Node.js 20.19+ ou 22.12+
- npm

## Desenvolvimento

```bash
npm install
npm run dev
```

## Verificações

```bash
npm run lint
npm run build
```

Para visualizar a versão de produção localmente, execute `npm run preview` depois do build.

O Tailwind CSS v4 está integrado pelo plugin `@tailwindcss/vite`. As classes utilitárias ficam disponíveis nos componentes React.
